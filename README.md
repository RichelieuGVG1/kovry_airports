# Ограничения в аэропортах Москвы — дашборд по каналу «Говорит Росавиация»

Скрипт разбирает JSON-экспорт Telegram-канала [«Говорит Росавиация»](https://t.me/rosaviatsia) и строит интерактивный HTML-дашборд о введении и снятии ограничений на приём и выпуск воздушных судов в четырёх аэропортах Москвы: Шереметьево, Внуково, Домодедово и Жуковском.

## Что показывает дашборд

- сколько ограничений вводили и в какие дни, месяцы и часы суток это происходило чаще всего;
- сколько времени проходило от введения ограничения до его снятия;
- свечные графики по часам и по месяцам: столбец — среднее или медиана, «фитиль» — разброс от минимума до максимума;
- переключатели «Количество / Продолжительность», «Среднее / Медиана», выбор года, сезона и месяца, режим «За всё время»;
- распределение по дням недели, продолжительность по часу введения и по сезонам, самые напряжённые дни.

Годы, сезоны и месяцы определяются по данным автоматически. Например, если в выгрузке появится 2027 год, он сам добавится во все графики и переключатели.

| Файл | Назначение |
|---|---|
| `moscow_restrictions_dashboard.py` | разбор выгрузки и сборка дашборда (только стандартная библиотека Python 3.8+) |

## Как получить данные

1. Откройте канал в Telegram Desktop.
2. Выберите «⋮ → Экспорт истории чата».
3. Укажите формат **JSON**; медиафайлы можно не выгружать.
4. Получившийся файл `result.json` и будет входными данными.

## Запуск локально

```bash
python moscow_restrictions_dashboard.py result.json -o dashboard.html
```

Дополнительные параметры:

```bash
# сохранить также таблицу ограничений
python moscow_restrictions_dashboard.py result.json -o dashboard.html --csv restrictions.csv --json-out restrictions.json

# встроить d3 в HTML, чтобы файл открывался без интернета
python moscow_restrictions_dashboard.py result.json -o dashboard.html --d3 d3.v7.min.js
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--auto-from` | `2025-05-01` | с какой даты сообщения разбираются автоматически |
| `--gap-hours` | `6` | новое введение спустя столько часов без снятия считается новым ограничением |
| `--max-hours` | `24` | более долгая продолжительность считается неизвестной (снятие не было опубликовано) |

Готовый `dashboard.html` открывается в любом браузере, сервер для этого не нужен.

## Запуск в Google Colab

1. Откройте `moscow_restrictions_colab.ipynb` в Colab («Файл → Загрузить блокнот»).
2. Выберите «Среда выполнения → Выполнить все».
3. Загрузите `result.json` с компьютера или укажите путь к нему на Google Диске.

Дашборд появится прямо в блокноте. Там же его можно скачать вместе с CSV или сохранить на Диск.

## Как считается

- **Ограничение** — это одно введение ограничений в одном аэропорту. Если одновременно закрыли три аэропорта, это три ограничения.
- Учитываются и полное закрытие, и работа «по согласованию с соответствующими органами». Если частичный режим сменял полный без снятия, это одно ограничение.
- **Время** берётся из текста сообщения («в 04:40 МСК»), а если его там нет — из времени публикации. Время везде московское.
- **Продолжительность** считается только тогда, когда в канале есть и сообщение о введении, и сообщение о снятии.
- **Сезоны** считаются внутри календарного года: зима — это январь, февраль и декабрь того же года.
- Сообщения о погодных ограничениях, сводки и сообщения авиакомпаний не учитываются.

## Ограничения

- Канал создан в августе 2023 года. До мая 2025 года он публиковал в основном итоговые сводки свободным текстом, поэтому эпизоды этого периода разобраны вручную и хранятся в скрипте списком (`EARLY_EVENTS`).
- Сообщения с мая 2025 года разбираются по формулировкам канала («ВВЕДЕНЫ», «СНЯТЫ», «по согласованию»). Если канал их сменит, часть сообщений может не распознаться. Признак этого — рост числа «сообщений о снятии без найденного введения» в сводке, которую печатает скрипт.
- Данные отражают только то, что опубликовано в канале. Это не официальная статистика.
