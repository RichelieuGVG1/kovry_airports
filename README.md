# КОВРЫ в аэропортах Москвы

Сей скрипт строит интерактивный HTML-дашборд о введении и снятии ограничений на приём и выпуск воздушных судов в аэропортах Шереметьево, Внуково, Домодедово и Жуковский.

## Возможности

Дашборд показывает число введённых ограничений по часам суток, дням недели и месяцам, а также время от введения до снятия. Основные графики построены в виде свечей: высота столбца соответствует среднему или медиане, «фитиль» показывает разброс от минимума до максимума. Отдельно выводятся продолжительность по часу введения и по сезонам, распределение по длительности и самые напряжённые дни.

Доступны переключатели «Количество / Продолжительность» и «Среднее / Медиана», выбор года, сезона и месяца, а также режим «За всё время».

Годы, сезоны и месяцы определяются по данным автоматически. При появлении в выгрузке новых периодов, например 2027 года, они добавляются во все графики и переключатели.

| `moscow_restrictions_dashboard.py` | разбор выгрузки и сборка дашборда (только стандартная библиотека Python 3.8+) |

## Получение данных

В Telegram Desktop откройте канал, выберите «⋮ → Экспорт истории чата» и укажите формат JSON. Медиафайлы выгружать не нужно. Входными данными служит полученный файл `result.json`.

## Запуск локально

```bash
python moscow_restrictions_dashboard.py result.json -o dashboard.html
```

Дополнительные параметры:

```bash
# сохранить также таблицу ограничений
python moscow_restrictions_dashboard.py result.json -o dashboard.html --csv restrictions.csv --json-out restrictions.json

# встроить d3 в HTML для работы без интернета
python moscow_restrictions_dashboard.py result.json -o dashboard.html --d3 d3.v7.min.js
```

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--auto-from` | `2025-05-01` | дата, с которой сообщения разбираются автоматически |
| `--gap-hours` | `6` | через сколько часов без снятия новое введение считается новым ограничением |
| `--max-hours` | `24` | порог, сверх которого продолжительность считается неизвестной |

Файл `dashboard.html` открывается в браузере, сервер не требуется. Без параметра `--d3` библиотека d3 загружается с cdnjs.

## Запуск в Google Colab

Загрузите `moscow_restrictions_colab.ipynb` через «Файл → Загрузить блокнот» и выполните «Среда выполнения → Выполнить все». Файл `result.json` загружается с компьютера или берётся с Google Диска по указанному пути. Дашборд отображается в блокноте; HTML и CSV можно скачать или сохранить на Диск.

## Методика

Ограничением считается одно введение ограничений в одном аэропорту: одновременное закрытие трёх аэропортов даёт три ограничения. Учитываются полное закрытие и работа «по согласованию с соответствующими органами». Переход от полного режима к частичному без снятия считается одним ограничением.

Время берётся из текста сообщения («в 04:40 МСК»), при его отсутствии — из времени публикации. Время московское. Продолжительность рассчитывается только при наличии сообщений и о введении, и о снятии.

Сезоны считаются внутри календарного года: зима — январь, февраль и декабрь одного года. Сообщения о погодных ограничениях, сводки и сообщения авиакомпаний не учитываются.

## Ограничения

Канал создан в августе 2023 года. До мая 2025 года он публиковал в основном итоговые сводки свободным текстом, поэтому эпизоды этого периода разобраны вручную и хранятся в скрипте в списке `EARLY_EVENTS`.

Сообщения начиная с мая 2025 года разбираются по формулировкам канала («ВВЕДЕНЫ», «СНЯТЫ», «по согласованию»). При их изменении часть сообщений может не распознаваться. Признак этого — рост числа сообщений о снятии без найденного введения в сводке, которую выводит скрипт.

Данные отражают только опубликованные в канале сообщения и не являются официальной статистикой.
